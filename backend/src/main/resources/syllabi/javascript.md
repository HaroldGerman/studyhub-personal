# Sílabo Calendarizado: Desarrollo Web Full Stack

Este sílabo está diseñado para un ritmo de estudio de **3 horas diarias (18-20 horas semanales)**. Está enfocado en la práctica intensiva y la consolidación de conceptos antes de avanzar.

---

## 📅 Calendario de Aprendizaje Semanal

### 🌐 FASE 1: Fundamentos y Maquetación Web (Semanas 1 - 5)

*   **Semana 1: Fundamentos de Internet e Infraestructura**
    *   *Día 1-2:* Arquitectura Cliente-Servidor. Protocolo HTTP/HTTPS. ¿Qué es DNS e IP?
    *   *Día 3-4:* Flujo de una petición web. Qué es un Dominio y un Hosting.
    *   *Día 5-6:* Introducción al Frontend vs Backend. Setup de VS Code y Terminal de comandos.
    *   *Entregable:* Diagrama técnico detallado del ciclo de una petición web.

*   **Semana 2: HTML5 Estructural y Semántica**
    *   *Día 1-2:* Etiquetas básicas y estructura de un documento HTML5.
    *   *Día 3-4:* Semántica web (`<main>`, `<article>`, `<aside>`, etc.) para SEO y Accesibilidad.
    *   *Día 5-6:* Formularios, inputs modernos y validaciones nativas.
    *   *Entregable:* Formulario de registro accesible con validaciones de datos nativas.

*   **Semana 3: CSS3 - Estilos y Flexbox**
    *   *Día 1-2:* Selectores CSS, Cascada, Especificidad y el Modelo de Caja (Box Model).
    *   *Día 3-4:* Posicionamiento (`static`, `relative`, `absolute`, `fixed`, `sticky`).
    *   *Día 5-6:* Flexbox: Ejes, alineación y distribución de elementos.
    *   *Entregable:* Maquetación de una barra de navegación y una sección de servicios con Flexbox.

*   **Semana 4: CSS3 Avanzado y Diseño Responsive**
    *   *Día 1-2:* CSS Grid: Filas, columnas, áreas y alineación.
    *   *Día 3-4:* Media Queries y diseño adaptativo (Mobile First).
    *   *Día 5-6:* Variables CSS, Transiciones y Animaciones básicas.
    *   *Proyecto 1:* 📄 **Página Personal Responsive (Portafolio v1)**.

*   **Semana 5: Git, GitHub y Maquetación con Tailwind CSS**
    *   *Día 1-2:* Configuración de Git, commits, ramas, merges y resolución de conflictos.
    *   *Día 3-4:* Subir código a GitHub, Pull Requests y README.md profesional.
    *   *Día 5-6:* Introducción a Tailwind CSS (Utility-first CSS) y maquetación ágil.
    *   *Entregable:* Portafolio v1 refactorizado y desplegado en GitHub Pages.

---

### ⚡ FASE 2: Programación y JS en el Navegador (Semanas 6 - 11)

*   **Semana 6: Fundamentos de JavaScript para Programadores**
    *   *Día 1-2:* Sintaxis, variables (`let`, `const`), tipos de datos dinámicos y operadores.
    *   *Día 3-4:* Estructuras de control de flujo (condicionales y bucles en JS vs Java/Python).
    *   *Día 5-6:* Funciones (flecha, anónimas, callbacks) y Concepto de Scope.
    *   *Entregable:* Script de consola para resolver problemas de lógica comunes.

*   **Semana 7: JavaScript Estructurado y POO**
    *   *Día 1-2:* Arrays, Objetos literales y métodos avanzados de arrays (`map`, `filter`, `reduce`).
    *   *Día 3-4:* Desestructuración, Spread y Rest operators.
    *   *Día 5-6:* Programación Orientada a Objetos en JS (Clases, prototipos, `this`, herencia).
    *   *Proyecto 2:* 🧮 **Calculadora Funcional e Interactiva**.

*   **Semana 8: Conceptos Avanzados de JavaScript**
    *   *Día 1-2:* Hoisting, Closures y contextos de ejecución.
    *   *Día 3-4:* Asincronía en JS: Callbacks, Promesas y sintaxis `async`/`await`.
    *   *Día 5-6:* Control y manejo de errores (`try/catch`).
    *   *Entregable:* Simulación asíncrona de procesamiento de pagos con promesas encadenadas.

*   **Semana 9: Manipulación del DOM y Eventos**
    *   *Día 1-2:* Selección de nodos, modificación de atributos, estilos y clases.
    *   *Día 3-4:* Event Listeners, propagación de eventos (bubbling) y prevención por defecto.
    *   *Día 5-6:* Creación dinámica de elementos del DOM.
    *   *Entregable:* Interfaz de calculadora interactiva conectada a la lógica del proyecto 2.

*   **Semana 10: APIs y Almacenamiento Web**
    *   *Día 1-2:* Persistencia de datos en el cliente con LocalStorage y SessionStorage.
    *   *Día 3-4:* Consumo de APIs REST usando `fetch` y procesamiento de JSON.
    *   *Día 5-6:* Manejo de estados de carga (loaders) y errores de red en la UI.
    *   *Proyecto 3:* 📝 **Lista de Tareas con LocalStorage**.
    *   *Proyecto 4:* 🌤️ **Aplicación del Clima con API pública**.

*   **Semana 11: TypeScript y Entornos de Build**
    *   *Día 1-2:* Configuración de proyectos modernos con **Vite**.
    *   *Día 3-4:* Fundamentos de TypeScript: Tipos explícitos, interfaces, uniones y genéricos.
    *   *Día 5-6:* Configuración de ESLint y Prettier.
    *   *Proyecto 5:* 🎬 **Buscador de Películas/Música utilizando TypeScript y Vite**.

---

### ⚛️ FASE 3: Desarrollo Frontend Moderno con React (Semanas 12 - 14)

*   **Semana 12: Fundamentos de React**
    *   *Día 1-2:* Arquitectura de componentes, JSX y renderizado dinámico.
    *   *Día 3-4:* Pasaje de datos mediante Props. Estado local (`useState`).
    *   *Día 5-6:* Eventos en React y renderizado condicional.
    *   *Entregable:* Clon de interfaz interactiva segmentada en componentes limpios.

*   **Semana 13: Hooks de React y Consumo de APIs**
    *   *Día 1-2:* Control de efectos secundarios con `useEffect`.
    *   *Día 3-4:* Referencias de elementos con `useRef` y creación de Custom Hooks.
    *   *Día 5-6:* Consumo de APIs con manejo de estados de carga/error en React.
    *   *Entregable:* Buscador de películas refactorizado completamente a React.

*   **Semana 14: Enrutamiento y Estado Global**
    *   *Día 1-2:* Navegación multipágina con React Router.
    *   *Día 3-4:* Gestión de estado global con Context API.
    *   *Día 5-6:* Buenas prácticas de estructura de carpetas en React.
    *   *Proyecto 6:* 🛒 **Tienda Web con Carrito de Compras y Checkout**.

---

### 🛡️ FASE 4: Desarrollo Backend y Base de Datos (Semanas 15 - 17)

*   **Semana 15: Node.js y Express**
    *   *Día 1-2:* Entorno de ejecución Node.js y arquitectura de servidores.
    *   *Día 3-4:* Creación de servidor con Express: ruteo y controladores.
    *   *Día 5-6:* Middlewares personalizados, validación de datos de entrada y CORS.
    *   *Entregable:* API básica de gestión de productos local.

*   **Semana 16: Bases de Datos Relacionales (PostgreSQL)**
    *   *Día 1-2:* Introducción a bases de datos relacionales. Instalación y configuración de PostgreSQL.
    *   *Día 3-4:* Diseño de esquemas de bases de datos, claves primarias/foráneas y relaciones.
    *   *Día 5-6:* Consultas SQL (SELECT, INSERT, UPDATE, DELETE, JOINs).
    *   *Entregable:* Diseño de base de datos relacional para un e-commerce en diagrama entidad-relación.

*   **Semana 17: ORM (Prisma), Seguridad y Autenticación**
    *   *Día 1-2:* Integración de PostgreSQL con Node.js usando **Prisma ORM** y migraciones.
    *   *Día 3-4:* Seguridad en Backend: Hash de contraseñas con `bcrypt` y variables de entorno.
    *   *Día 5-6:* Autenticación basada en JSON Web Tokens (JWT) y roles.
    *   *Proyecto 8:* ⚙️ **API REST de Comercio Electrónico con base de datos y autenticación**.

---

### 🤝 FASE 5: Integración Full Stack, Calidad y Despliegue (Semanas 18 - 22)

*   **Semana 18: Conexión Frontend y Backend**
    *   *Día 1-2:* Conectar la aplicación de React con la API de Node.js.
    *   *Día 3-4:* Flujo de Login y Registro desde la interfaz de usuario.
    *   *Día 5-6:* Almacenamiento seguro de tokens y persistencia de sesión.
    *   *Entregable:* Formulario de Login funcional conectado a base de datos.

*   **Semana 19: CRUD Completo y Panel de Control**
    *   *Día 1-2:* Implementación de operaciones Create, Read, Update, Delete completas.
    *   *Día 3-4:* Panel administrativo con permisos específicos de rol (Admin vs Usuario).
    *   *Día 5-6:* Subida de imágenes y manejo de archivos.
    *   *Proyecto 7/9/10:* 🖥️ **Aplicación Full Stack Integrada**.

*   **Semana 20: Pruebas unitarias y de integración**
    *   *Día 1-2:* Introducción al testing automatizado con **Vitest** en Frontend.
    *   *Día 3-4:* Pruebas de rutas y lógica en el Backend con **Supertest**.
    *   *Día 5-6:* Principios de Clean Code y refactorización orientada a SOLID.
    *   *Entregable:* Suite de pruebas unitarias para las funciones de autenticación y carrito de compras.

*   **Semanas 21 - 22: Despliegue, CI/CD y Proyecto Final**
    *   *Día 1-3:* Contenedores con Docker. Pipelines básicos de CI/CD (GitHub Actions).
    *   *Día 4-6:* Despliegue de DB (Neon/Supabase), Backend (Render/Railway), Frontend (Vercel) con HTTPS.
    *   *Semanas Completas:* Desarrollo del **Proyecto Final Profesional** e inserción al portafolio.
    *   *Proyecto 11:* 🚀 **Proyecto de Portafolio Profesional Desplegado en Producción**.
